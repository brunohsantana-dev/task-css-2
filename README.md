# Easy Shopping Via Mobile

Página responsiva desenvolvida para praticar HTML e CSS.

A responsive landing page built to practice HTML and CSS.

---

## Português

### Sobre o projeto

Miniprojeto desenvolvido durante meus estudos no DevClub, com uma página de apresentação sobre compras pelo celular.

Após criar a versão inicial, adaptei o layout para computadores, tablets e celulares.

### Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts — Oswald
- Git e GitHub

### O que pratiquei

- Estruturação de conteúdo com HTML.
- Organização do layout com CSS Grid e Flexbox.
- Uso de media queries.
- Dimensionamento de imagens para diferentes telas.
- Fontes e espaçamentos flexíveis com `clamp()`.
- Efeitos de interação com `:hover` e `:active`.
- Versionamento com Git e uso de branches.

### Responsividade

- **Desktop:** texto e ilustração em duas colunas, com fundo cinza na área da imagem.
- **Tablet e celular:** seções empilhadas em uma coluna.
- **Celular:** ajustes nos espaçamentos, fontes e tamanho da imagem.

### Como visualizar

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.

### Status

Projeto de estudo com foco em layout e responsividade. Os links de navegação e o botão “Get Started” ainda não possuem funcionalidades implementadas.

## English

### About the project

A small project developed during my studies at DevClub, featuring a landing page about mobile shopping.

After building the initial version, I adapted the layout for desktops, tablets, and phones.

### Technologies used

- HTML5
- CSS3
- Google Fonts — Oswald
- Git and GitHub

### What I practiced

- Structuring content with HTML.
- Organizing layouts with CSS Grid and Flexbox.
- Using media queries.
- Sizing images for different screens.
- Creating flexible typography and spacing with `clamp()`.
- Adding interaction effects with `:hover` and `:active`.
- Version control with Git and working with branches.

### Responsive design

- **Desktop:** text and illustration in two columns, with a gray background behind the image.
- **Tablets and phones:** sections stacked in a single column.
- **Phones:** additional adjustments to spacing, typography, and image size.

### How to view

Download or clone the repository and open `index.html` in your browser.
